# Panorama Stitcher

โปรเจกต์ demo สำหรับต่อภาพพาโนรามาอัตโนมัติ ทำงานทั้งหมดในเบราว์เซอร์ด้วย [OpenCV.js](https://docs.opencv.org/4.9.0/opencv.js) ไม่มีเซิร์ฟเวอร์ ไม่มีการอัปโหลดรูปไปที่ไหน

## วิธีรัน

เปิดแบบ local file (`file://`) ตรงๆ อาจมีปัญหาเรื่อง CORS กับบางเบราว์เซอร์ แนะนำให้รันผ่าน local server เล็กๆ แทน เช่น:

```bash
cd panorama-stitcher
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์

หรือจะ deploy เป็น static site (GitHub Pages, Netlify, Vercel ฯลฯ) ก็ได้เลย เพราะเป็นแค่ HTML/CSS/JS ธรรมดา ไม่มี build step

## วิธีใช้

1. ลากรูป (หรือเลือกไฟล์) ที่ถ่ายต่อเนื่องกัน — เรียงจากซ้ายไปขวา
2. ถ้าลำดับผิด ลากรูปในแถบฟิล์มเพื่อสลับตำแหน่งได้
3. กด "ประกบภาพ"
4. ดาวน์โหลดผลลัพธ์เป็น PNG

## อัลกอริทึม

ต่อภาพทีละคู่ตามลำดับ (ซ้ายไปขวา) ด้วย pipeline มาตรฐาน:

1. ตรวจจับจุดเด่นด้วย **ORB**
2. จับคู่จุดเด่นด้วย **Brute-Force Matcher (Hamming distance)** + Lowe's ratio test (0.75)
3. หา **Homography** ด้วย RANSAC จากคู่จุดที่แมตช์กัน
4. วาร์ปภาพที่สองเข้าสู่ระบบพิกัดของภาพแรก แล้ววางซ้อนกัน (overwrite แบบไม่มี feathering)

## ข้อจำกัด (เพราะเป็น demo)

- **ไม่มี feathering/blending ที่รอยต่อ** — อาจเห็นรอยตะเข็บชัดถ้าแสง/สีของภาพต่างกันมาก ถ้าอยากได้คุณภาพระดับโปรดักชัน ควรเพิ่ม multi-band blending และ exposure compensation
- ภาพถูกย่อขนาดสูงสุด 1600px ต่อด้านก่อนประมวลผล (เพื่อความเร็ว/หน่วยความจำ) — ปรับได้ที่ค่า `MAX_DIM` ใน `app.js`
- ต่อภาพแบบ sequential (1→2→3→...) เหมาะกับภาพแนวนอนเรียงกันเป็นแถวเดียว ไม่รองรับ layout แบบตาราง/หลายแถว
- ต้องการ overlap ระหว่างภาพติดกันอย่างน้อยประมาณ 20-25% และมีลวดลาย/รายละเอียดพอให้ ORB จับจุดเด่นได้ (ภาพท้องฟ้าเรียบๆ ล้วนจะหาจุดเชื่อมไม่เจอ)
- ไม่รองรับวัตถุเคลื่อนไหวระหว่างเฟรม (คนเดิน รถวิ่งผ่าน) จะทำให้เห็นภาพซ้อน/ผีที่รอยต่อ

## ต่อยอดได้

- เพิ่ม feathering/multi-band blending ที่รอยต่อ
- รองรับ cylindrical/spherical warping สำหรับพาโนรามามุมกว้างมากๆ
- ทำ bundle adjustment แทนการต่อทีละคู่ เพื่อลด drift สะสมเมื่อภาพเยอะ
- ย้าย pipeline ไป backend (Python + OpenCV, ใช้ `cv2.Stitcher`) ถ้าต้องการความแม่นยำ/ความเร็วสูงขึ้นสำหรับรูปจำนวนมากหรือไฟล์ใหญ่
